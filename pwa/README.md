# تندرست (PWA)
نسخه وب‌اپلیکیشن تندرست در پوشه `pwa/` قرار دارد.

## اجرا و نصب
- اگر GitHub Pages برای مخزن فعال باشد، نشانی برنامه: https://mehranbakhtarani-gif.github.io/tandorost/pwa/
- صفحه را با Chrome در Android باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را بزنید.
- برای نصب PWA، HTTPS لازم است.

## امکانات
- ثبت دستی مسافت و مدت پیاده‌روی
- ثبت وعده غذایی و کالری تخمینی
- ثبت آب و عادت‌های روزانه
- پروفایل و محاسبه BMI
- ذخیره محلی و پشتیبان‌گیری/بازیابی JSON
- کش آفلاین از طریق Service Worker

## محدودیت‌ها
این نسخه ردیابی GPS، همگام‌سازی ابری، حساب کاربری یا پایش پزشکی ندارد. داده‌ها روی همان مرورگر و دستگاه باقی می‌مانند.

انتشار خودکار: GitHub Actions workflow `.github/workflows/pages.yml`.
