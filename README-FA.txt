تندرست – نسخه PWA

این پوشه نسخه وب‌اپلیکیشن تندرست است.
برای نصب روی گوشی‌های مختلف، پوشه باید روی یک نشانی HTTPS منتشر شود؛ باز کردن index.html به‌صورت فایل مستقیم، نصب PWA را فعال نمی‌کند.

ویژگی‌ها:
- قابل نصب از مرورگرهای سازگار با PWA روی اندروید
- پوسته آفلاین با Service Worker
- ذخیره اطلاعات روزانه در حافظه محلی مرورگر همان دستگاه (Local Storage)
- خروجی و بازیابی فایل پشتیبان JSON
- ثبت مسیر با GPS پس از اجازه کاربر؛ حالت شبیه‌سازی جداگانه مشخص شده
- ثبت دستی غذا از فهرست؛ عکس فقط در صفحه پیش‌نمایش محلی است و برای تحلیل به سرور ارسال نمی‌شود

نکته حریم خصوصی:
کد برنامه و فایل‌های ثابت روی میزبان HTTPS قرار می‌گیرند، اما داده‌های ثبت‌شده در این نسخه به سرور ارسال نمی‌شوند. پاک کردن داده‌های مرورگر یا حذف برنامه ممکن است داده‌های محلی را حذف کند؛ مرتب فایل پشتیبان بگیرید.

انتشار:
1) تمام محتویات این پوشه را بدون تغییر ساختار روی یک میزبان استاتیک HTTPS قرار دهید.
2) آدرس منتشرشده را با Chrome در Android باز کنید.
3) از منوی مرورگر گزینه Install app / Add to Home screen را بزنید.
4) برای استفاده آفلاین، ابتدا یک‌بار برنامه را با اینترنت باز کنید.

محدودیت‌ها:
- شمارش قدم‌ها از حسگر سخت‌افزاری گوشی در این نسخه فعال نیست؛ GPS و تخمین قدم از مسافت یا ورود دستی به کار می‌رود.
- تشخیص خودکار کالری از عکس فعال نیست؛ برای جلوگیری از ارسال تصویر خصوصی به سرویس بیرونی، ثبت غذا دستی است.
- اطلاعات بین گوشی‌ها همگام‌سازی نمی‌شود؛ هر گوشی فضای ذخیره مستقل دارد.
